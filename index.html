The datasets behind open LLM model families — browsable, linked to source, sampled row-by-row.

Currently featuring

NVIDIA Nemotron since 2023

Every dataset collection NVIDIA has published for the Nemotron model family, pulled live from the Hugging Face Hub collections API, grouped exactly as NVIDIA groups them — pre-training, post-training, and topic-specific sets like math, code, safety, and agentic tool-use. Each dataset links back to its Hugging Face page and shows 16 sampled rows pulled straight from the dataset viewer, no download required.

Data pulled via the Hugging Face Hub API and the datasets-server rows API. Sample rows belong to their original dataset authors and licenses — follow each dataset's link for full terms.
