Methodology. "Training throughput" and "GPU setup" are quoted directly from the source when the project reports them. "Est. training GPU-hours" is only quoted directly when the source states it explicitly; otherwise it's computed as GPU count × wall-clock training time and marked "computed" so it's clear it's a derived estimate, not a reported figure. TinyLlama's own paper independently reports 3,456 GPU-hours for a 300B-token training run on this hardware, which scales linearly to ~34,560 GPU-hours for the full 3T-token run — consistent with the computed figure above.

Sources: TinyLlama GitHub repo and the TinyLlama paper (arXiv:2401.02385).
